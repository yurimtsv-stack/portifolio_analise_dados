# 📊 Dashboard de Análise de Dados — SAC
📌 Esse Projeto se consiste em criar um relatório de SAC usando Power BI de modo a tornar fácil o entendimento do assunto proposto.
---
🛠️ Ferramentas Utilizadas
- Microsoft Power BI: Limpeza, tratamento e manipulação da base de dados.
- Funções DAX: Criando novas medidas e variáveis de dados.
---
# 🎯 Objetivo
Criar um dashboard interativo e visual que permita:

- Identificar o tempo de atendimento de clientes e o total de chamadas
- Verificar os feedback de atendentes mais ativos e bem avaliados
- Problemas e motivo dos problemas
- Números relacionados a cada atendente e problemas, como tempo de resposta, cancelamentos, etc...

# 🔍 Principais Insights

Durante a análise dos dados, foi possível identificar:

- Tempo de atendimento
- Tem médio de retorno do atendimento por mês e ano
- Media de chamadas diárias
- Total de atendimentos
- Percentual de cancelamentos
- Atendimentos por atendente e por problemas

# Esses insights podem ser utilizados para:

- Identificar e orientar atendentes menos avaliados para ajudar a melhorar o atendimento
- Verificar quais fatores estão entre as menos bem avaliadas e quais decisões tomar para melhorar
- Verificar quais períodos do ano tem mais número de interação com clientes e aumentar ou reduzir a carga de funcionários
- Analisar de modo geral os números na base de dados e entender onde está errando e acertando
- Verificar quais fatores levam a boa análise dos clientes
