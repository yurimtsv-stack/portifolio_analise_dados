# Estudo completo usando MySQL

Este arquivo é um estudo envolvendo MySQL, simulando, simplificando e usando comandos de maneira explicativa e sem enrolação desde os mais básicos até os avançados.

A proposta consiste em estudar o conceito básico e a sintaxe de Banco de Dados MySQL e entender ele até o final.

---
🛠️ Ferramentas Utilizadas
- MySQL Workbench - Desenvolvido e mantido pela Oracle.
---
# 🎯 Objetivo

- Entender MySQL na prática
- Simplificar a sintaxe e suas funções
- Entender como manipular e editar tabelas
- Saber fazer o que for proposto pela equipe de modo simples e compreensível

---
# 🔍 Principais Comandos Aprendidos

- Select sendo o mais básico entre eles para selecionar tabelas, colunas ou dados de uma tabela quando acompanhada de filtros.
- Filtrar dados de modo simples e inteligente mesclando o comando Select com operadores como Or, And, In, Between, Like % x % e Where.
- Saber separar dados e ordena-los em pequenas colunas usando operadores Order By, Asc, Desc.
- Uso de operadores aritméticos como sum, avg, min, max, mult, etc...
- Agrupamento de valores únicos ou distintos como Group By ou Distintc.
- Relacionamentos de tabelas com Iner Join.
- Deletar, acrescentar ou atualizar dados em tabelas com Create Table, Drop, Delete, outros.
   
# Esses comandos são usados para:
- Tratar grandes volumes de dados em empresas de maneira rápida e eficiente.
- Garantir que os dados estejam corretos e sem anormalidades em sua análise e limpeza.
- Permitir que sejam organizados e tratados para serem apresentados ou transformados em relatórios.
