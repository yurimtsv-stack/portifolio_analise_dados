# 📊 Dashboard de Análise de Dados — Recursos Humanos
📌 Sobre o Projeto

Este projeto foi desenvolvido como parte do meu portfólio com o objetivo de demonstrar minhas habilidades em análise de dados aplicada a Gestão de RH.

A proposta consiste em analisar dados de funcionários, seja ativos ou inativos e os dados financeiros da empresa.
---
🛠️ Ferramentas Utilizadas
- Microsoft Excel: Limpando e formulando novos dados, finalizando no Dashboard de Recursos Humanos (RH).
---
# 🎯 Objetivo
Criar um dashboard que permita analisar por ANO:

- A quantidade de funcionários Ativos e Inativos
- Observar a distribuição de cada funcionário por setor
- Qual Gestor tem maior e menor número de funcionários em seu setor
- Analisar os salários distribuídos contando tanto ativos quanto inativos e o total.

# 🔍 Principais Insights

Durante a análise dos dados, foi possível identificar:

- O número exato de funcionários Ativos e Inativos em 4 anos
- A distribuição de salários pagos ao longo dos 4 anos
- Distribuição de funcionários por setor na empresa
- Quantos são admitidos e desligados por Mês
- Feedback de cada funcionário que está ou já passou pela empresa

# Esses insights podem ser utilizados para:

- Orientar vagas específicas para o setor que está com baixo número de funcionários 
- Verificar qual razão da Atividade ou Inatividade afim de criar modelos de gestão para amenizar ou melhorar os casos e feedbacks
- Número exato de funcionários e sua distribuição para cada setor
